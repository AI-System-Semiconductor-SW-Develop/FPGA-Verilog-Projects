# 4비트 2:1 멀티플렉서

[전체 프로젝트 목록](../README.md)

두 4비트 입력 중 하나를 선택하고 입력 값도 LED로 표시합니다.

## 동작과 설계

- `sel=1`: `out[3:0] = a[3:0]`
- `sel=0`: `out[3:0] = b[3:0]`
- `led[3:0] = a`, `led[7:4] = b`

예를 들어 `a=0001`, `b=1000`이면 `sel`을 1에서 0으로 바꿀 때 출력이 `0001`에서 `1000`으로 바뀝니다. 테스트벤치는 비트 위치를 바꾸며 입력 선택을 확인합니다. 보고서와 현재 RTL의 포트 구성을 함께 확인할 수 있습니다.

## 실행 구성

- **Design Top:** `mux4bit`
- **Design Sources:**
  - [mux4bit.v](sources_1/mux4bit.v)
- **보드 제약:** XDC 미포함. 보드 실행에는 Top 포트에 맞는 핀 제약이 필요합니다.

Vivado 프로젝트 생성과 합성·보드 실행 절차는 [공통 실행 방법](../README.md#실행-방법)을 따릅니다. 위 소스만 Design Sources에 추가하고 테스트벤치는 Simulation Sources에 분리합니다.
